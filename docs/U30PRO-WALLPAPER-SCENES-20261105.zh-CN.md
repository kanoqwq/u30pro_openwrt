# 动态壁纸按场景播放

移植来源：
- [c0d52d26](https://github.com/33333s/U30pro-openwrt/commit/c0d52d26d71509868c6bd3c3802475cc54f50cb9)：场景选择、屏幕策略和后端。
- [4b0aab6f](https://github.com/33333s/U30pro-openwrt/commit/4b0aab6f90221f6559ec2bb1f9a9494728f4ba6c)：更正原作者的 CPU 测量说明，无代码变更。

只引入壁纸相关部分，没有导入上游的发布参数、固定分区地址、启动窗口或内核配置。
源码仍保留在 devices/u30pro/native，并通过 adaptations.json 记录原始和本地摘要。

网页“屏幕壁纸”支持分别勾选锁屏、主页、信号、流量、功能列表、功能子页、
控制中心和短信列表、密码盘、弹窗；“全部界面”同步全部选择，全部取消表示静态。
中、英、土语言及官方/Aurora 主题沿用本地实现，保存期间禁用整个场景组，继续使用
可自动消失且不叠加的通知。之前的图片/视频缩放修复及 240/480px 分辨率不变。

实体屏幕“功能 → 显示 → 动态壁纸”依次选择关闭、锁屏、锁屏和主页、全部界面；
网页选择其他组合时显示“自定义”，再点击回到关闭。睡眠、触摸、翻页、抽屉动画及
列表惯性滚动时暂停播放，未选界面保持暂停帧；没有新增播放线程或轮询服务。

新增 display.wp_live_pages 是 0–511 的场景位图，位顺序与上游一致。后端 get/set
和 RPC 方法签名均接入 pages；仍接受旧 live 参数，旧 live 单独写入会清除场景位图。
不带新字段的旧配置保留原来的 0/1/2 含义，不会因升级默认启用全部场景。设置场景
时同时维护 wp_live，保留原有第三方主题读取协议。仅修改玻璃效果不覆盖场景选择。

原作者第二条提交修正的测量，是解锁、玻璃模糊为 0 时播放约占一个小核的
26–38%，未播放约 1%；这是上游那台机器的实测，不是本仓库实机验收或续航承诺。
本地说明仅提醒播放增加 CPU/电量消耗，不把该比例当作所有配置的保证。

验证：
- tests/u30pro_wallpaper_scenes.py：实际原生 C 屏幕场景矩阵、暂停、预设、保存重读；
  目标 ucode 后端及 RPC 签名、0/511/自定义位图、旧配置、非法输入和玻璃单独保存。
- tests/u30pro_wallpaper_browser.py：24 种语言/主题/明暗/宽度组合，真实浏览器复选框、
  全选/取消/部分选择、保存中禁用、上传、删除、通知不叠加。
- tests/u30pro_wallpaper_scale_browser.py：真实 Canvas/Video 缩放，不退化上次修复。
- 原生屏幕重编、生产 sources/finish 收录和实际准备根检查；未修改内核。

本轮没有热部署或覆盖已交付 ZIP。实屏播放效果及本机 CPU 占用留待用户后续确认。

## 后续分块编码与局部重绘

继续移植 [3c2759ea](https://github.com/33333s/U30pro-openwrt/commit/3c2759ea98ab9292f8849136cc637fe8d067bd6f)
和 [302d1d12](https://github.com/33333s/U30pro-openwrt/commit/302d1d120e9a34de440000d22b579a6041e3b957)。
前者新增 U3LW v2 无损 16×16 分块差值、zlib 压缩和基于背景覆盖关系的局部重绘，
在 SPI 提交上一帧期间准备下一帧；后者整理带参数的测试工具并更正性能记录。

支持 CompressionStream 的浏览器生成 v2 屏幕文件；不支持的浏览器仍生成 v1 JPEG。
旧文件继续播放，网页提示可重新选择原视频提升清晰度。480px 网页预览仍使用 v1，
保留第三方主题协议。原生暂停、场景、手势、电源菜单和充电控制不变。
另外补齐空闲内存分配失败重试、首帧必须为关键帧、文件尾和 zlib 头校验。

原作者修订记录的主页数据约为新格式 16.6 fps/25% CPU，旧格式 16 fps/35% CPU；
这些是上游指定配置的测量，不是本地实测或对其他视频的性能承诺。
本地增加真实 Chromium 编码与独立逐字节解码检查、原生跳帧/循环/旧格式/畸形文件，
以及九个场景、四种玻璃色调下的局部重绘与整页重绘像素对照；目标 ucode 同时检查
新旧文件上传、版本回报、非法文件拒绝且保留旧壁纸。
本次仅需重新编译屏幕程序，内核未改动。
