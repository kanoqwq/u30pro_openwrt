## 原厂依据

- 本机正在使用的原厂设备树：充电器与 FGU 都有 `monitored-battery-0/1`。
  两套电池的正常 CV 均为 4400000 µV，额定/满充容量不同；温控表含独立的
  温度边界、恢复温度、电流和电压。45–50°C 档 CV 为 4100000 µV；
  45°C 边界恢复点是 42°C，50°C 停充边界恢复点是 48°C。
- 用户提供的 `MU5358_Android15_kernel(6.6.46).tar.gz` 中，
  `bsp_kernel/kernel6.6/unisoc/drivers/unisoc_platform/sprd_charger/sprd_battery_info.c`
  SHA256 `b1b113389bc352c836f93509def6b5eb4083b41e774969ba34186c3b11b210ea`：
  按电池电阻 ID 选择 `monitored-battery-N`，再读取该节点的
  `constant-charge-voltage-max-microvolt`、各供电类型电流与 JEITA 四列数据。
  对照使用的是配置解析行为；此源码不能代替当前机器完整 Android 策略实测。
- [SGMICRO 官方 SGM41513 手册 REG04](https://www.sg-micro.com/rect/assets/58a4fe4d-da1d-49a3-b312-5664211d9016/SGM41513_SGM41513A_SGM41513D.pdf)：
  编码 15 为 4.35 V 特殊值，其余有效编码按规定步进解释。

参考源码仅按文件提取到忽略的 work 调查目录，没有引入第二份内核构建树、
私有固件或本地文件依赖。正式编译只使用本仓库代码和原有登记工作区。

## 修正

1. 充电器与 FGU 共用电池 ID 选择函数，从各自原厂 phandle 获取同一配置。
   不再选择全局第一个 `simple-battery`。ID、phandle 或参数无效时明确返回错误，
   不猜测另一款电池。
2. 正常 CV 来自选中电池配置；启动寄存器只用于诊断，不作为永久上限。
   温控降压后能按温度恢复；较低电压的有效电池配置仍保持其自身上限。
3. CV 编码选择不超过目标的最高可表达值，保留精确 4.35 V 编码。
4. 按每个温度边界的恢复点逐档迁移，替代固定 3°C 的近似。
   高温停充后可先恢复到温热降压档，再进入正常档，不跳过必要保护。

保留用户暂停/限流、公共定量限充、BC1.2、PD、OTG 与芯片其他保护位。
不修改百分比、强制校准、NV、IMEI、充电安全计时器或回充阈值。
F50 Pro 的无电池配置仍在加载电池策略前排除。

## 验证边界

生产 C 函数的离线用例覆盖：继承温热降压值后恢复正常 CV、较低 CV、所有
有效 CV 编码及 769 个目标电压、冷热迟滞边界、跨多档恢复、两套电池 ID、
错误/缺失 ID 或 phandle、非法配置和 OF 引用释放；原有 PD、用户限流、
暂停、OTG 和通知生命周期用例继续执行。测试已接入正式 native 回归入口。

修复前离线重现的条件是“启动时寄存器仍为温热降压值”；尚未证实故障机
满足该条件。当前没有进行修改后实机充满、Android 对照循环或故障机验收。
