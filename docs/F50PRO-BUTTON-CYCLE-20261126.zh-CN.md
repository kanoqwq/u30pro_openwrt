# F50 Pro 快捷键切卡方式

后续切卡指示灯反馈与更新交付验证见 [信号灯反馈](F50PRO-SIM-KEY-FEEDBACK-20261127.zh-CN.md)。

网页入口：设备管理 → 实体按键 → 快捷键切卡方式。

- 默认 `pair`：在现有 owner 报出的 `logical_cards[0]`、`logical_cards[1]` 之间
  切换上网卡，包括内置／外置混搭；不重新选择两路物理卡源。
- 可选 `list`：保留原来的全部卡源循环，顺序与 SIM 管理一致，外置1为原生 ID4、
  外置2为 ID3。卡源范围仍由机型／产品形态的 owner 提供。
- 只影响已经设置为「切换上网卡」的按键动作，不改按键绑定、即时单击或关机长按。
  设置保存在 `unisoc_modem.main.f50pro_button_cycle`，没有设置时按 `pair` 解释；
  旧客户端保存其他按键设置不会覆盖它，保存本身不执行切卡。
- 新选择算法为 `mu300.button-cycle` ucode；既有 Python 按键接口只增加配置字段和
  调用胶水。每次按键使用实时 SPSWDATA 数据栈和 `logical_cards`，不缓存卡对、
  不依据旧保存值猜卡，也不在卡源未知时偷偷回到列表循环。
- 最终执行仍是既有 `data-sim apply data f50pro-card-N`，GPIO、AT owner、锁及恢复
  流程未修改。U30 Pro 后续同步见 [U30 Pro 策略接入](U30PRO-BUTTON-CYCLE-20261127.zh-CN.md)；
  MU300、E5 不在本策略变更范围。

说明压缩成「仅影响切卡快捷键，保存不切卡。」一行，去掉长篇按键时序提示，收紧
段落和保存按钮前间距；中文、英文、土耳其文及 PO／LMO 已同步。

## 六轮离线回归

| 轮次 | 内容 |
| --- | --- |
| 1 | 实际 ARM64 ucode：七种 board 配置的实时双卡、混搭、双向切换及卡源更新 |
| 2 | 与原列表行为比较：各产品形态顺序、外置编号、单选项；Python 分发经过实际 ucode 再交给原 apply 接口 |
| 3 | 无效／未知卡源、旧保存值、无效模式均不执行切换；20,000 次连续选择中途换卡对，无持久状态 |
| 4 | 实际 HTTP → uhttpd → rpcd：四机型保存、换会话读取、无效值拒绝、其他配置保留及匿名／只读写入拒绝 |
| 5 | 实际普通更新及 Diff Studio／OTA：首次加入、第二次更新与撤销，保留策略、两路卡源、按键命令、Wi-Fi 和插件数据 |
| 6 | 24 种浏览器组合：四机型 × 中英土 × 手机／桌面；默认值、模式保存、错误恢复、只读和隐藏；既有按键及翻译回归 |
